# Teknologi — Maniak Aksesoris

| Lapisan | Pilihan |
| --- | --- |
| Markup | HTML5 semantik |
| Tampilan | CSS3, Flexbox, Grid, media query |
| Logika | JavaScript ES modules tanpa framework |
| Katalog | Array produk pada `js/data.js` |
| Keranjang | localStorage untuk ID dan jumlah |
| Pemesanan | Draf melalui tautan WhatsApp `wa.me` |
| Aset | Ilustrasi SVG lokal, tanpa hotlink |
| Hosting | Hosting statis HTTPS; belum dipublikasikan |
| Tes | Node.js test runner dan browser smoke test opsional |

Harga dibaca dari katalog dan tidak disimpan sebagai nilai otoritatif dalam browser. Kontak pemesan tidak masuk localStorage. Tidak ada backend, akun, stok real-time, atau pembayaran.

Targetkan browser modern Chrome, Edge, Firefox, Safari, Android, dan iOS. Verifikasi perangkat dan browser tambahan sebelum rilis.
